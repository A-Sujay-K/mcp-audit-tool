## Reporting a Vulnerability

We take the security of MCP-Sentinel seriously. If you discover a security vulnerability in this project, please report it privately:

1. **GitHub Security Advisory**: Submit a private advisory report at [github.com/A-Sujay-K/mcp-audit-tool/security/advisories/new](https://github.com/A-Sujay-K/mcp-audit-tool/security/advisories/new).
2. **Direct Email**: If GitHub Advisories is inaccessible, email `akarshsujaykumar.23is@saividya.ac.in` with the subject `[SECURITY] MCP-Sentinel Vulnerability Report`.

Please include:
- A description of the vulnerability and potential impact.
- Steps or a minimal proof-of-concept reproducing the issue.
- Any suggested remediations or mitigations.

We will acknowledge receipt within 48 hours and provide a coordinated disclosure timeline.
